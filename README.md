# まなびクエスト 🦉

小学6年生〜中学生のための **学習アプリ＋実力診断テスト**。
iPad の Safari（ホーム画面に追加）や Pixel の Chrome で、アプリのように全画面・オフラインで動く PWA です。

- 忘却曲線（FSRS）で「忘れかけたころ」に自動で復習
- まちがえた問題・苦手な単元を多めに出題
- 適応型テスト（CAT）で **推定偏差値** と苦手単元を診断
- 暗記ものは **爆速周回**（フラッシュカード／60秒タイムアタック／聞き流し）
- 解説は最初から内蔵。さらに **AI先生（フクロン先生）** が詳しく解説・質問に回答・学習レポート・苦手克服問題の自動作成
- 効果音・XP・レベル・称号・バッジ・デイリーミッション・連続学習記録
- 音声読み上げ・音声入力（ブラウザ標準機能なので無料）、Apple Pencil の手書き（漢字の書き取り・計算メモ）
- 問題は CSV / JSON で **あとから追加可能**（中学の問題もどんどん増やせる）

**公開URL：https://sleipnir167.github.io/manabi-quest/**（iPad の Safari で開いて「ホーム画面に追加」）

## 2. iPad / Pixel で使う（公開してホーム画面に追加）

PWA は **HTTPS** で公開する必要があります。

### GitHub Pages（設定済み）
`main` ブランチにプッシュすると、GitHub Actions（`.github/workflows/deploy.yml`）がテスト → ビルド → 公開まで自動で行います。
問題パックを `public/packs/` に追加してプッシュするだけで、アプリ側にも自動で配信されます。

### ほかのサービスに置く場合
Cloudflare Pages などでも動きます。

1. `npm run build` → `dist/` フォルダができる
2. Cloudflare Pages（または Netlify / GitHub Pages）に `dist/` をアップロード
   - Cloudflare Pages：ダッシュボード → Workers & Pages → 作成 → Pages → 「アセットをアップロード」で `dist` をドラッグ
   - GitHub Pages でも `base: './'` 設定済みなのでサブパスでそのまま動きます
3. iPad の Safari で URL を開き、共有ボタン →「**ホーム画面に追加**」
4. Pixel の Chrome ではメニュー ⋮ →「**アプリをインストール**」

Oracle Cloud に置く場合は nginx / Caddy で `dist/` を配信し、HTTPS（Let's Encrypt）を有効にしてください。

> 学習記録は **端末の中（IndexedDB）** に保存されます。設定 → データ から定期的にバックアップ（JSON）を保存できます。

## 3. AI の設定（クレジットをほぼ使わない工夫つき）

設定 → 🦉 AI で接続先を設定します。**上から順に試し、失敗したら次へ自動で切りかわります。**

| 順番 | 接続先 | 説明 |
|---|---|---|
| 1 | OpenRouter（無料モデル） | `google/gemma-4-31b-it:free, qwen/qwen3.8-27b:free, openrouter/free` を初期設定。`:free` はクレジット消費なし（1日の回数制限あり）。「無料モデル一覧」ボタンで最新の無料モデルを確認できます |
| 2 | 無料LLM API（Modelix / FreeLLMAPI など） | OpenAI 互換の `/v1` URL を入れるだけ |
| 3 | OpenRouter（低価格モデル） | `deepseek/deepseek-v4-flash` など。解説1回あたり約0.01円〜0.1円 |
| 4 | 自前サーバー（Gemma / Ollama） | Oracle Cloud の Gemma など。遅い場合は待ち時間を120秒以上に |

OpenRouter の APIキーは 1 と 3 で共通です（どちらかに入れれば OK）。

### クレジット節約のしくみ
1. すべての問題に **内蔵の解説** があるので、AI は「もっと詳しく」のときだけ呼ぶ
2. 一度作った AI 解説は **端末に保存（キャッシュ）** → 同じ質問は二度とお金がかからない（「保存済み・無料」と表示）
3. 無料モデル → 無料 API → 低価格モデルの順に **自動フォールバック**
4. **1日の利用回数の上限**・回答の長さを設定可能。今月の利用回数と費用の目安も表示
5. 学習レポートは 1週間分を小さくまとめた数値だけを送信（数百トークン）
6. 「ミスの傾向」「苦手単元」「おすすめ」などの分析は **AIを使わず端末内で計算**（無料）

### 自前 Gemma（Oracle Cloud）をつなぐとき
アプリは HTTPS で動くため、サーバー側も **HTTPS ＋ CORS 許可** が必要です。

- Ollama の場合：`OLLAMA_ORIGINS=*` を設定して起動
- Caddy で HTTPS 化する例：
  ```
  ai.example.com {
    reverse_proxy localhost:11434
  }
  ```
- アプリの URL 欄に `https://ai.example.com/v1`、モデル欄に `gemma3:4b` など

### APIキーを iPad に置きたくない場合（任意）
`proxy/worker.js` を Cloudflare Workers に置くと、キーをサーバー側だけに保存できます（ファイル冒頭に手順）。
さらに 設定 → データ・保護者 →「保護者ロック」で AI 設定を暗証番号で保護できます。

### 動作確認だけしたいとき（クレジット不要）
```bash
node scripts/mock-ai.mjs
```
AI の URL に `http://localhost:8787/v1`、モデルに `mock` を入れると、にせ AI で解説・問題生成の動きを確認できます（開発用）。

## 4. 問題を追加する（中学の問題もどんどん）

### A. アプリから読み込む（いちばん簡単）
設定 → 📦 問題パック →「CSVテンプレート」をダウンロード → Excel / Google スプレッドシートで編集 → CSV 保存 →「ファイルを読み込む」。

| 列 | 内容 |
|---|---|
| subject | 国語 / 算数・数学（math） / 理科 / 社会 / 英語 |
| grade | 6=小6、7=中1、8=中2、9=中3 |
| unit_id / unit_name | 単元 ID（半角英数）と名前。同じ ID は同じ単元にまとまる |
| type | 空欄なら自動。`choice`(4択) / `input`(入力) / `numeric`(数) / `tf`(○×) / `order`(並べ替え) |
| prompt | 問題文。分数は `[[3/4]]`、帯分数 `[[1 3/4]]`、下線 `__語__`、太字 `**語**`、改行 `\n` |
| answer | 正解。tf は `o` か `x`、order は `A|B|C`（正しい順） |
| wrong1〜3 | 選択式の誤答（入れると4択になる） |
| explanation | 解説 |
| difficulty | 1〜5（推定偏差値の計算に使う） |
| accept | 別解（`|` 区切り） |

### B. サーバーに置いて自動配信
`public/packs/` に JSON を置き、`public/packs/index.json` に追記して公開し直すだけ。
アプリは起動時に新しいパック・バージョンアップしたパックを **自動でインストール** します（サンプル：`chu1-chiri-start.json`）。

```json
{ "packs": [ { "id": "chu1-chiri-start", "file": "chu1-chiri-start.json", "version": 1 } ] }
```

内容を直したら `version` を上げてください。JSON の書式は `docs/pack-format.md` を参照。

### C. AI に作らせる
設定 → AI →「問題を作る」。苦手単元を選ぶと、その単元の4択問題を AI が作って「AI作成問題」パックに追加します（中身の確認・削除も可能）。

## 5. 学習のしくみ

| 機能 | しくみ |
|---|---|
| 復習のタイミング | **FSRS-4.5**（Anki でも使われる最新の忘却曲線モデル）。正解の速さ・ヒント使用から自動で評価し、「思い出せる確率」が目標（初期90%）を下回るころに再出題 |
| まちがえた問題 | 同じセットの数問後にもう一度出し（その場で覚え直し）、10分後以降にも再出題。間違いノートに自動保存 |
| おまかせ学習 | 期限が来た復習 50% ・苦手 20% ・新しい問題 30%。新しい問題は「今の実力に合った難しさ」を優先し、教科・単元を混ぜて出す（インターリーブ） |
| 推定偏差値 | **項目反応理論（3PLモデル）**。問題の難易度（1〜5）と学年から難しさを決め、ベイズ推定（EAP）で実力 θ を推定 → 偏差値 = 50 + 10θ |
| 実力診断テスト | **適応型テスト（CAT）**。いまの推定実力で最も情報量が大きい問題を、単元が偏らないように選ぶ。15問程度で推定 |
| 日々の実力推移 | 毎回の回答で θ を少しずつ更新（Elo 方式）し、日ごとに記録 → 「推定偏差値の推移」グラフ |
| ミスの傾向 | 約分わすれ・符号ミス・うっかり（速すぎる誤答）・知識不足などを自動判定して集計 |
| 計算問題 | 分数・比・速さ・割合・円の面積・体積・場合の数・データ・正負の数・文字式・一次方程式・てこ・密度など **24種類の自動生成**（途中式つき解説・図つき）。無限に練習できる |

## 7. 開発者向け

```
src/
  content/        問題データ（banks）・自動生成（generators）・単元・パック登録（registry）
  lib/            fsrs（忘却曲線）/ irt（偏差値推定）/ selection（出題）/ record（記録）/ ai / speech / sound / stats …
  components/     QuestionView（解答UI）, Keypad, DrawPad, charts, Mascot …
  screens/        Home, Learn, Player, Rapid, Test, Notebook, Stats, Settings
tests/            vitest（判定・アルゴリズム・全生成問題の検算・問題データの整合性）
public/packs/     サーバー配信する追加問題パック
proxy/worker.js   （任意）AIプロキシ
scripts/          アイコン生成・にせAIサーバー
```

- 問題を内蔵で増やす：`src/content/banks/*.ts` に `C()`（4択）`TF()` `I()`（入力）`N()`（数）`O()`（並べ替え）で追記
- 計算の自動生成を増やす：`src/content/generators/index.ts` に生成器を追加（テストが自動で200パターン検算）
- アイコン再生成：`npm run icons`
